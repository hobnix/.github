# Hobnix

A NixOS home server you can read: Incus containers on ZFS or SnapRAID, Samba shares, backups, a web interface and one command, `hs`, to run it all.

| Repository | What it is |
| --- | --- |
| [server](https://github.com/hobnix/server) | The core: NixOS configuration, the `hs` command and the web interface |
| [recipes](https://github.com/hobnix/recipes) | Apps for your server, installed with `hs pkg` |
| [extensions](https://github.com/hobnix/extensions) | Optional parts of the server, installed with `hs pkg` |

Start with the [server README](https://github.com/hobnix/server#readme) and the guides in its `docs/` folder.
